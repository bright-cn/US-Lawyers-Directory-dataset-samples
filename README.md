| 字段名称 | 描述 |
|------------|-------------|
| `url` | 律师专业资料页面的 URL 链接。 |
| `address` | 律师的办公地址。 |

| `isln` | 国际标准律师编号，用于唯一标识律师。 |
| `law_school_attended` | 律师获得学位的法学院。 |
| `location` | 律师主要执业所在地。 |
| `name` | 律师的全名。 |
| `practice_count` | 与律师相关联的法律业务机构或办公室数量。 |

| `university_attended` | 律师完成本科学位的大学。 |
| `year_of_first_admission` | 律师首次获准执业的年份。 |
| `filial` | 律师执业机构的分支或分部所在地。 |
| `people` | 律师专业人脉网络中的相关人员或联系人。 |
| `awards` | 律师获得的专业奖项和认可。 |
| `profile_peer_review_count` | 律师收到的同行评价数量。 |
| `profile_peer_review_star` | 同行评价的平均星级。 |
| `profile_peer_review_awards` | 基于同行评价获得的奖项。 |
| `fax` | 律师办公室的传真号码。 |
| `languages` | 律师使用的语言。 |
| `mailing_address` | 用于与律师通信的邮寄地址。 |
| `office_hours` | 律师事务所的办公时间。 |
| `office_size` | 律师办公室或律所的规模。 |
| `phone` | 律师的联系电话。 |
| `photo` | 律师的照片。 |
| `profile_peer_review_detail` | 同行评价的详细信息。 |
| `profile_visibility` | 律师个人资料对公众的可见状态。 |
| `video_call` | 是否提供用于咨询的视频通话服务。 |
| `website` | 律师或律师事务所官方网站的 URL。 |
| `biography` | 律师的简要传记或背景介绍。 |
| `birth_information` | 律师出生日期和地点的信息。 |
| `memberships` | 律师的专业会员资格及所属组织。 |
| `hobbies_interests` | 律师的爱好和个人兴趣。 |
| `profile_client_recomendation_count` | 收到的客户推荐数量。 |
| `profile_client_recomendation_rating` | 客户推荐的平均评分。 |
| `profile_client_review_count` | 收到的客户评价总数。 |
| `profile_client_review_detail` | 客户评价的详细信息。 |
| `profile_client_review_list` | 客户评价列表。 |
| `profile_client_review_rating` | 客户评价的平均评分。 |
| `clients` | 律师代理过的知名客户。 |
| `clients2` | 其他客户或客户群体。 |
| `year_established` | 律师执业机构成立的年份。 |
| `about` | 有关律师执业或理念的其他信息。 |
| `payment_information` | 付款方式和条款信息。 |
| `state_bar_summary` | 律师在州律师协会的会员资格及资质状态摘要。 |
| `transactions` | 律师处理过的重大交易或案件。 |
| `minority_owned` | 律师事务所是否为少数族裔所有。 |
| `phone_cell` | 用于直接联系律师的手机号码。 |
| `phone_telecopier` | 律师的传真号码。 |
| `company` | 律师所属律师事务所或公司的名称。 |


## 使用场景

### 1. 法律市场分析
通过分析律师的执业领域、所在地和获准执业年份等数据，深入了解法律行业。

### 2. 人脉拓展机会
通过探索所属组织、会员资格和法律业务专长，发现潜在的人脉拓展机会。

### 3. 竞争对手基准分析
通过查看同行评价、客户推荐和专业奖项，与竞争对手进行基准比较。
